# 1.4.0 密码访问兼容验证

2026-10-25。范围：访问有网页密码的 LibreTV 部署时自动弹框，验证前阻止功能使用；保存会话使下次启动免输入，并保留明确开放的免密码部署兼容性。

## 实现

- 启动和换服务先验证 `/api/status`。需要密码时通过 `/api/auth` 提交密码，接收 `ltv_session`，再次确认已验证后才提交服务配置。
- 应用私有存储仅保存会话、期限、Secure 和路径信息，不保存明文密码。每次新进程启动仍向服务确认有效性。
- 有效会话按规范化协议、主机、端口、部署路径隔离。接口、封面和播放器使用同一作用域；登录 API 禁止重定向。手机仅获得 LAN 会话和按搜索结果 ID 限定的封面入口。
- 本地到期和真实站点会话撤销会重新锁定；资源自身的 401 先复查站点状态，避免误清有效登录。候选失败、旧请求及旧到期回调不能覆盖新验证。
