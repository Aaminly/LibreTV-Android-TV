## 发现并修正

- 换片时旧剧集仍可操作：回归测试先失败，修复后完整模拟器流程通过。
- 放大二维码共享已回收位图：取消手工回收，更新/离开时关闭预览；后台与返回检查通过。
- 原始 URL 剧集统一显示“播放”：新增标签测试，复用同一编号规则于手机/详情/播放器；真实 52 集面板复验通过。
- 手机多个调用触发重复轮询：保持单一在途状态请求，页面隐藏停止轮询。
