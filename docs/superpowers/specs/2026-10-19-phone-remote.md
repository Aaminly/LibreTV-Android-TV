# 手机选片与电视遥控

电视侧栏设置下方常驻二维码；手机在同一局域网扫码进入真实网页。在手机搜索与显示来源明确的结果；点击结果获取详情，单集直接播放，多集在手机选集后电视播放。沿用兔子与青绿色视觉，手机双列海报、清晰错误/空状态、底部悬浮播放条与安全区留白。播放器进度、播放暂停、换集和退出状态均以电视为准，手机拖动期间不被轮询覆盖。

复用现有 LibreTvApi、Media3、观看历史和 LAN 服务。连接跨 MainActivity/PlaybackActivity 保留；应用后台后关闭，重新进入生成新令牌。仅前台应用接收命令；无新增 Android 权限或后台服务。状态每秒读取，页面隐藏暂停轮询；失败显示断开并禁用控制。命令携带当前媒体标识，拒绝过期控制，防止切片后旧拖动影响新片。所有电视播放器访问主线程，服务器后台线程执行搜索。未授权令牌、跨站来源、非法参数拒绝。

范围包括原生侧栏、生命周期、播放器桥接、HTTP 协议、手机页面、测试、版本说明与公开仓库。保留用户设置/记录和原签名。版本 1.3.0 code 4。验收为 JVM 协议测试、电视实际手机选片播放/暂停/seek/遥控反向同步/后台失效、375 与 393 手机视口视觉检查、APK 签名与远端一致性。

最新验收调整：用户关机后明确要求不再测试/安装实体电视；本轮使用本机模拟器与浏览器，并推送代码、保留 APK，实体电视安装等用户次日通知。
